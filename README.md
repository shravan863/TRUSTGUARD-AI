# TrustGuard AI

## 🚀 Live Demo

👉 [Click here to use TrustGuard AI](https://trustguard-ai-upto.onrender.com)

## 📌 Project Description

TrustGuard AI is a Python and Flask-based web application that analyzes suspicious messages and URLs for potential scam and phishing indicators. It calculates a risk score and classifies the input as LOW, MEDIUM, or HIGH risk.

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Scikit-learn
- NumPy

## ✨ Features

- Scam message analysis
- Phishing URL analysis
- Risk score calculation
- LOW, MEDIUM and HIGH risk classification
- Simple web interfaceWhat TrustGuard AI does
